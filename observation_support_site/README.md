# 관측 출장지 지원 시스템 — 분리본

원본 `index.html`에 포함되어 있던 코드를 다음 세 파일로 분리했습니다.

- `index.html`: 문서 구조
- `styles.css`: 화면 스타일
- `script.js`: 사용자 상호작용

`index.html`을 브라우저에서 열면 됩니다.

## 검토 결과

1. 원본은 UTF-8이며, 분리본에서도 한글이 정상 보존됩니다.
2. `.rank`의 `align-items:12px`는 유효하지 않아 `align-items:center`로 수정했습니다.
3. 버튼 이벤트는 동작하지만 메모 저장은 실제 저장소에 기록하지 않고 알림만 표시합니다.
4. 주소 검색과 AI 추천은 현재 정적 데모이며 실제 지도·검색 API와 연결되어 있지 않습니다.
5. PDF 버튼은 PDF 파일 생성이 아니라 브라우저 인쇄 창을 엽니다.
6. 반복 카드와 비교표 데이터가 HTML에 직접 들어 있어, 항목이 늘어나면 JavaScript 데이터 기반 렌더링으로 바꾸는 편이 유지보수에 유리합니다.

이번 분리본은 원본의 구조와 동작을 유지하면서 HTML·CSS·JavaScript를 분리하고, 확인된 CSS 오류 한 곳만 수정한 버전입니다.
